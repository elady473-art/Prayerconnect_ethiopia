# PrayerConnect Ethiopia 🙏

### A Prayer and Spiritual Support Platform

PrayerConnect Ethiopia is a responsive web application designed to help people connect through prayer, share prayer requests, encourage one another with Bible verses, and record personal spiritual journeys.

The platform is designed for the Ethiopian Orthodox Christian community, with support for both Amharic and English.

## ✨ Features

- **Prayer Wall:** Share and explore prayer requests.
- **Private and Public Requests:** Choose whether a prayer request is public or private.
- **Anonymous Requests:** Submit prayer requests without displaying your name.
- **Prayer Support:** Click "I Prayed" to show support for a request.
- **Answered Prayers:** Mark prayer requests as answered.
- **Daily Bible Verse:** Display an encouraging Scripture verse.
- **Prayer Journal:** Record personal prayers and spiritual reflections.
- **Amharic and English:** Switch between the two languages.
- **Dark and Light Mode:** Choose a comfortable display theme.
- **Search and Filters:** Find prayer requests by keyword or category.
- **Responsive Design:** Access the application on desktop, tablet, and mobile devices.
- **Interactive Notifications:** Receive feedback through toast messages.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
